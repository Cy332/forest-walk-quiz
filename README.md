# 【HW5 作業規格書】荒林之境：靈魂行囊的抉擇之旅 (The Forest Walk)

---

## 一、 專案基本資訊與設計動機

* **專案名稱**：荒林之境：靈魂行囊的抉擇之旅 (The Forest Walk: A Journey of Soul & Burden)
* **交付形式**：單一檔案 `index.html`（CSS 與 JavaScript 完整內嵌，零外部圖檔與 MP3 依賴，支援本機直接點擊開啟與 GitHub Pages 零報錯部署）。
* **心理測驗核心架構**：改編自經典投射心理測驗「森林穿越測驗（Forest Journey Test）」，透過冒險情境引導使用者面對伴侶、孩子、金錢與自我責任時的直覺抉擇。
* **象徵意義核心對照矩陣**：
* 🦍 **猩猩 (Gorilla)**：伴侶／情人／另一半（象徵親密關係、依靠與情感負擔）
* 🐦 **小鳥 (Bird)**：孩子／視如己出、需細心呵護的弱小對象
* 🐍 **青蛇 (Snake)**：金錢／財富（象徵現實資產、生存慾望與潛在危機感）
* 🎒 **背包 (Backpack)**：責任感／對生活與未來的承擔（生存包袱與自我期許）



---

## 二、 系統架構與技術亮點 (Vibe Coding Highlights)

### 1. 實體拖曳互動系統 (Physical Drag & Drop System)

跳脫傳統心理測驗「靜態單選題」的機械感，全面導入 HTML5 Drag and Drop API 與 Mobile Touch Event。場景中建構動態互動舞台（Visual Stage），中央放置帶有微幅呼吸動畫（Breathe Animation）的旅人 SVG 剪影，使用者需親手將四個同伴拖曳至「肩頭/高處」、「身側牽繫」、「背負容納」、「隨行跟隨」等不同槽位（Drop Slots）。

### 2. 無破圖自主渲染機制

全站角色與場景採用原生 SVG 向量圖形與高解析 Emoji 封裝，不需額外下載圖片，確保離線與任何裝置都能 100% 完整呈現。

### 3. 純原生 Web Audio API 合成音效

完全摒棄外部 MP3/WAV 音檔，由瀏覽器原生 `AudioContext` 振盪器（OscillatorNode）即時演算音頻：

* `playTone()`：清脆水滴/木魚互動音（點擊與拖曳放下時觸發）。
* `playAlertSound()`：低頻 120Hz 鋸齒波緊張音效（急流危機關卡）。
* `playChord()`：破曉五度空靈大和弦（C-E-G-B 漸強晨音）。
* 右上角常駐音效開關（Mute Switch），尊重使用者環境。

### 4. 動態沉浸氛圍

背景利用 HTML5 Canvas 繪製 35 顆自主飄動、具備微光閃爍效果的螢火蟲光點，營造幽暗森林的深層沉浸感。

## 三、 使用者體驗流程與劇本規格 (User Flow & Storyline)

整個 Web App 採單頁狀態機推進（SPA State Machine），切換時帶有淡入淡出（Fade-in / Slide-up）過渡：

```
[Scene 0: 幽林破曉・啟程] ── (背景故事、音效控制、啟程按鈕)
           ↓ (點擊踏入深林)
[Scene 1: 晨光攜物・編隊] ── (自由拖曳 4 物件至旅人 4 大槽位)
           ↓ (四物件皆配置完成解鎖按鈕)
[Scene 2: 湍流急瀑・搶救] ── (暴雨斷橋，拖曳第一時間先救誰至守護之環)
           ↓ (救援完成解鎖按鈕)
[Scene 3: 暮色寒夜・取暖] ── (氣溫驟降，拖曳最能撫慰心靈者至取暖槽位)
           ↓ (選擇完成解鎖按鈕)
[Scene 4: 破曉晨曦・星圖] ── (卡片翻面揭曉象徵、五維長條圖、封號、文字複製與重置)

```

### 【Scene 0：幽林破曉・啟程 (Prologue)】

* **介面佈局**：頂部 PROLOGUE 徽章、主標題、背景情境引言、四大同行者圖示展示區。
* **互動邏輯**：點擊「踏入深林」按鈕，初始化 AudioContext 並播放啟程和弦，平滑切換至 Scene 1。

### 【Scene 1：晨光攜物・啟程編隊 (Arrangement)】

* **情境氛圍**：微光透出林間，旅人站在中央，四個同伴正在等待分配。
* **舞台元件**：
* **待拖曳區（Draggables Bar）**：🦍 猩猩、🐦 小鳥、🐍 青蛇、🎒 背包。
* **旅人剪影周圍設有 4 個精確定位槽位**：
1. `slot-shoulder`（肩頭/高處）：象徵無比珍視、呵護或置於最高地位。
2. `slot-hand`（身側牽繫）：象徵並肩同行、情感依託與平等相待。
3. `slot-back`（背負容納）：象徵由自我一肩承擔、保護於身後。
4. `slot-ground`（隨行跟隨）：象徵保持距離、給予自由或不施加過多束縛。




* **互動規則**：支援桌面拖曳與手機觸控；每個槽位只能容納一個物件（若已有物件會自動換位）；只有當 4 個物件全部被安置在槽位後，「邁向深處」按鈕才會從禁用（disabled）狀態解鎖亮起。

### 【Scene 2：湍流急瀑・極限搶救 (Crisis Management)】

* **情境氛圍**：背景光暈轉為暗紅，播放低頻震盪音效，表現山洪斷橋危機。
* **互動考驗**：「浪頭打來的瞬間，你本能只能死命救下一個！」
* **操作設計**：使用者需將最想優先保護的同伴拖曳至舞台中央發光的「守護之環」中。放開後即時觸發水滴音並解鎖下一步按鈕。

### 【Scene 3：暮色迷霧・依傍取暖 (Support System)】

* **情境氛圍**：背景轉為微暖橘紅光，象徵樹洞裡的微弱營火，寒風呼嘯。
* **互動考驗**：「體力透支、氣溫驟降時，誰是支撐你明日繼續走下去的靈魂支柱？」
* **操作設計**：將一個最能帶來安慰的夥伴拖曳至「取暖依偎」槽位，確認潛意識中最深層的精神支撐點。

### 【Scene 4：破曉晨曦・星盤報告 (Final Analysis & Reveal)】

* **視覺轉場**：背景泛起晨光金黃，播放通關清脆和弦。
* **四大象徵卡片**：以 2x2 網格清晰列出猩猩、小鳥、青蛇、背包對應的真實象徵含義。
* **四維能量指標長條圖（Dynamic Progress Bars）**：
* 伴侶情感牽絆 (猩猩) %
* 純粹呵護本能 (小鳥) %
* 現實資產掌控 (青蛇) %
* 自我責任承擔 (背包) %
* *演算規則*：彙整 Scene 1（位置權重：肩頭+20、身側+15、背負+15、隨行+5）＋ Scene 2（危機先救+35）＋ Scene 3（取暖支柱+25），進行標準化正規化計算，並以 CSS 過渡平滑展延長條圖。


* **專屬靈魂封號與深度分析**：
* 最高分若為猩猩：【執子之手的深情守望者】
* 最高分若為小鳥：【以愛築巢的純粹羽翼】
* 最高分若為青蛇：【務實清醒的現實掌舵家】
* 最高分若為背包：【堅毅自律的負重孤勇者】


* **操作輔助**：
* 「📋 複製測驗文字」：呼叫 Clipboard API 將排版工整的結果複製至剪貼簿，並彈出微光 Toast 提示。
* 「↺ 重啟森林之旅」：一鍵重設所有槽位與狀態機。

## 四、 迭代歷程與修改紀錄 (AI Collaboration & Optimization)

* **初版設計反思**：最初版本採用常見的文字卡片單選題。雖然邏輯完整，但互動形式較為傳統，缺少沉浸冒險的「Vibe 感」。
* **音效架構重構**：為了避免在 GitHub Pages 部署時因外部 MP3 載入失敗或路徑錯誤導致 404，與 AI 討論後將音訊模組重構為純原生 Web Audio API，以振盪器合成音頻，徹底消弭外部依賴。
* **互動手感升級**：將單純的按鈕點擊，重構為具有物理操作感的「Drag & Drop 拖曳舞台」，並在中央設計了呼吸動態的旅人 SVG 剪影與四大位置槽位，同時相容滑鼠事件與手機 Touch 事件，大幅提高作品完整度與趣味性。
